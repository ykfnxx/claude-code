# 第九章：命令系统与服务层

## 9.1 命令系统

### 9.1.1 命令类型

`src/types/command.ts` 定义了三种命令类型：

```
┌─────────────────────────────────────────────────┐
│ Command Type Hierarchy                            │
├─────────────────────────────────────────────────┤
│                                                   │
│ PromptCommand (type='prompt')                     │
│   ├── 模型可调用的skill                              │
│   ├── 内容展开到对话中                               │
│   └── 示例: /commit, /review, /compact              │
│                                                   │
│ LocalCommand (type='local')                       │
│   ├── 客户端本地命令                               │
│   ├── lazy-loaded call() 函数                      │
│   └── 示例: /login, /logout, /doctor               │
│                                                   │
│ LocalJSXCommand (type='local-jsx')                │
│   ├── 渲染React/Ink UI的命令                        │
│   ├── 完整的交互式界面                              │
│   └── 示例: /mcp (MCP管理界面)                      │
└─────────────────────────────────────────────────┘
```

### 9.1.2 命令注册

`src/commands.ts` (~25K行) 管理所有命令的注册和加载：

**命令来源**（按优先级排列）：

```
1. Bundled skills (skills/bundled/)
   └── 内置skill命令 (batch, loop, claudeApi, scheduleRemoteAgents)

2. Built-in plugin skills
   └── 内置插件提供的skill

3. Skill directory commands (skills/)
   └── 用户自定义skill目录中的命令

4. Workflow commands (feature-gated)
   └── 工作流脚本命令

5. Plugin commands + skills
   └── 第三方插件提供的命令和skill

6. Built-in commands (COMMANDS array, ~80+)
   └── 核心内置命令
```

### 9.1.4 Skill 工具集成

`SkillTool` (`src/tools/SkillTool/`) 与命令系统集成：

```typescript
// commands.ts 中的关键函数
getSkillToolCommands()    // 获取所有可作为skill tool使用的命令
getSlashCommandToolSkills()  // 获取slash命令型skill
assembleToolPool()  // 合并built-in + MCP + skill tools
```

Skill 类型的命令（`type='prompt'`）通过 `SkillTool` 暴露给模型，模型可以调用 `SkillTool` 执行这些 skill，skill 的内容会展开为完整的 prompt。

### 9.2.5 Compact 服务 (`services/compact/`)

对话上下文压缩引擎：

```
services/compact/
├── compact.ts         # 主压缩逻辑 (~1,667行)
├── autoCompact.ts     # 自动压缩触发 + 断路器
├── microCompact.ts    # 微压缩 (工具结果清除)
├── apiMicrocompact.ts # API侧微压缩
├── reactiveCompact.ts # 响应式压缩 (prompt-too-long后)
├── snipCompact.ts     # 截断压缩 (feature-gated)
├── snipProjection.ts  # 截断投影
├── prompt.ts          # 压缩提示词模板 (374行)
└── cachedMCConfig.ts  # 缓存微压缩配置

压缩类型:
1. Auto-Compact:  自动触发, 监控token使用量
2. Micro-Compact: 清除旧工具结果
3. Reactive Compact:  prompt-too-long后的实时压缩
4. Snip Compact: 截断旧历史 (feature-gated)
5. Session Memory Compact: 提取结构化笔记
```

### 9.2.6 OAuth 服务 (`services/oauth/`)

OAuth 2.0 认证流：

```
认证流程:
1. 用户运行 /login
2. 打开浏览器到 Anthropic OAuth 授权页
3. 用户授权后回调到本地服务器
4. 获取 access_token + refresh_token
5. 存储到 macOS Keychain (或等效存储)
6. 后续API调用自动附带 Bearer token

Token刷新:
- 401错误时自动刷新
- 另一进程刷新token时通过 "token revoked" 消息检测
```
